
# Agro Essencial – Simulador Agrícola com IA

Este projeto é um MVP de uma plataforma que auxilia produtores rurais a tomarem decisões financeiras baseadas em dados. Desenvolvido com Python e Streamlit.

## Funcionalidades:
- Simulação de lucro de até 3 culturas
- Análise de cenários (pessimista, realista, otimista)
- Recomendação de melhor opção
- Visualização gráfica

## Como rodar localmente:

```bash
pip install -r requirements.txt
streamlit run app.py
```
